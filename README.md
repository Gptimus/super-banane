# Super Banane · Monter une infra qui tient la charge

Notice interactive en 3D (en français) : comment faire évoluer une infrastructure web en 8 étapes, du laptop du développeur à la base de données répliquée.

**Site : https://gptimus.github.io/super-banane/**

## Étapes

1. Le site tourne sur le laptop du dev
2. Un serveur dans un datacenter
3. Scaling vertical
4. Séparer application et base de données
5. Scaling horizontal et load balancer
6. Plusieurs load balancers répartis par le DNS
7. Sharding de la base
8. Réplication primaire / réplicas

Les capacités et les prix affichés sont des ordres de grandeur issus d'un modèle simplifié.

Fichier unique : `index.html` (three.js chargé depuis jsDelivr).
